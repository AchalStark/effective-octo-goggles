# Vehicle Parking App

A modern web-based parking management solution that streamlines the parking experience for both users and administrators. This comprehensive system enables efficient parking spot reservations, real-time availability tracking, and automated billing while providing powerful administrative tools for facility management.

## Features

### 🚗 **Smart Parking Reservations**
Reserve parking spots instantly with real-time availability updates. Users can browse parking lots, check pricing, and secure their preferred spots with just a few clicks, complete with automatic spot assignment and confirmation.

### 📊 **Interactive Analytics Dashboard**
Comprehensive data visualization with interactive charts showing parking patterns, spending trends, and usage statistics. Users can track their parking history while administrators get system-wide insights for better decision making.

### 💰 **Automated Billing System**
Precise time-based cost calculation with automatic billing upon parking session completion. The system tracks entry and exit times, calculates costs based on hourly rates, and maintains detailed financial records.

### 🏢 **Multi-Location Management**
Support for multiple parking facilities with individual pricing, capacity management, and location-specific settings. Each parking lot can be configured with custom rates, maximum spots, and detailed address information.

### 👥 **Dual User Interface**
Separate interfaces for regular users and administrators. Users get a streamlined booking experience while admins access powerful management tools for lots, users, and system monitoring.

### 📱 **Real-Time Status Tracking**
Live updates on parking spot availability, active reservations, and occupancy rates. The system provides instant feedback on spot status changes and maintains accurate availability counts.

### 🔐 **Secure Session Management**
Robust authentication system with secure login/logout functionality, session protection, and user profile management. Enhanced security features prevent unauthorized access and ensure data privacy.

## Technologies Used

### **Backend Framework**
- **Flask** - Python web framework for robust server-side development
- **Flask-SQLAlchemy** - Database ORM for efficient data management
- **Flask-Login** - User authentication and session handling
- **Flask-WTF** - Form processing with CSRF protection

### **Database & Storage**
- **SQLite** - Lightweight relational database for data persistence
- **SQLAlchemy** - Database abstraction layer and query builder

### **Frontend Technologies**
- **HTML5 & CSS3** - Modern markup and styling
- **Bootstrap 5.3.0** - Responsive UI framework with mobile-first design
- **JavaScript (ES6)** - Dynamic client-side functionality
- **Chart.js** - Interactive data visualization library
- **Bootstrap Icons** - Comprehensive icon set

### **Development Architecture**
- **Blueprint Pattern** - Modular Flask application structure
- **Jinja2 Templates** - Server-side template rendering
- **WTForms** - Form validation and processing
- **Application Factory** - Scalable Flask app configuration
